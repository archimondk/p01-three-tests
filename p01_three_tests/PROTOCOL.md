## 0. 这份方案能支持什么样的表述

三重检验的判定规则最初是在 2026 年 8 月审计旧数据（2025Q1–2026Q2 提取）时形成的，**不是**事先注册的方案。本方案把这些规则连同修正一起固定下来，然后再用于质控中心重新提取的数据。

因此稿件中可以写：*the decision rules were fixed and publicly time-stamped before the updated extract was received and analysed*。

不能写成预注册，也不能把更新数据的结果称为独立验证，原因有两点：

- 新提取与旧提取在 2025Q1–2026Q1 重叠，大部分记录已经被看过；
- 真正未见过的只有新增季度，以及旧季度中被补报或修改的记录。

后者的规模由第 11 节的新旧比对给出。

## 2. 数据

- **来源**：省中医医院感染管理质控平台的季度申报表，机构层面汇总数据，不含患者信息。
- **时间窗口**：平台上线以来全部已截止的季度，以质控中心说明为准。窗口不写死到某个季度，季度由文件名识别（`t_YY_S_Q.csv`）。
- **主分析季度**：除被第 1 节 D4 规则或质控中心标记为不完整的季度外，其余季度全部纳入。不完整季度只用于敏感性分析，并做上报构成诊断（Table S2）。
- **读入校验**：
  - 每个季度文件必须包含全部必需字段，缺字段即停止；
  - 字段改名只能通过 `config.COLUMN_ALIASES` 映射。
- **重复记录**：
  - 完全相同的重复行删除并计数；
  - 同一机构同一季度存在内容不同的多行时，流程停止，须与质控中心核实。v1.6 的 `audit.py` 会静默保留第一行，这里不再这样处理。
- **率的计算**：一律由分子 / 分母重算，不使用平台计算的率字段。
- **机构属性**：级别取主分析期内最后一次上报的值。

## 4. 上报状态与分析可得性

**模块状态**。每个监测模块按分母取三种状态之一：

- 2：可分析，分母 ≥ 务实阈值；
- 1：分母存在但低于阈值；
- 0：分母为 0 或缺失，原因不可判定。

另记录状态 0 属于“空白”还是“填 0”。这一信息只用于描述，不进入判定。

**指标可分析的条件**：所属模块状态为 2，且分子未被清洗置缺失。

**分析可得性指数**：`INDEX_MODULES` 中状态为 2 的模块所占比例（见 D1）。

另算两个敏感性版本：

- 核心模块指数（综合感染、手卫生、病原学送检、I 类切口），用来回应“指数主要反映专科服务配置”的质疑；
- v1.6 的 10 模块指数。

指数在任何地方都不解释为监测质量、监测能力或真实感染负担。

## 5. Test 1：分析可得性

**判定规则**（务实阈值同 v1.6）：

| 判定 | 条件 |
|---|---|
| Pass | 可分析记录 ≥ 80%，且有可分析数据的机构 ≥ 50% |
| Conditional | 可分析记录在 50%–80% 之间 |
| Fail | 可分析记录 < 50%，或有可分析数据的机构 < 50% |

**精度阈值压力检验**：次级检验，不进入判定。

- 感染结局（发病密度及 SSI、血透感染等感染比例）：在合并率下期望事件数 ≥ 1.96² 所需的分母；
- 过程比例：95% CI 半宽 ≤ 5 个百分点所需的分母；
- 合并率按分母 > 0 且分子非缺失的记录计算。

v1.6 正文把规则写成“incidence-density 与 proportion 两类”，与代码不符，需改为上面的“感染结局与过程比例”两类。

## 6. Test 2：信度

- **模型**：随机截距模型，REML 估计 ICC。用解析剖面化的一维目标函数计算，并在每个指标上与 statsmodels MixedLM 交叉核对（Table S10）。
- **纳入**：每家机构至少 2 个可分析季度，至少 20 家机构，否则判为不可估计。
- **变换**：固定写在 `config.INDICATORS` 里，8 个感染结局用 log(1+x)，3 个过程指标和指数不变换。v1.6 由数据偏度（skew > 1）临时决定，换一批数据就可能改变变换方式；冻结前须按第 16 节第 3 步核对固定列表与 v1.6 的实际选择一致。
- **置信区间**：机构层面整群自助重抽 5 000 次，每次用同一 REML 估计量，取百分位区间。随机种子 `20261019`，每个指标一条独立随机流。v1.6 的 `p9a` 用 `hash()` 生成种子，每次运行结果都不同，且其输出与 `p10` 的 5 000 次结果并存，这正是正文与表格数字不一致的来源。
- **判定**：

  | 判定 | 条件 |
  |---|---|
  | Pass | 区间下限 ≥ 0.70 |
  | Provisional | 点估计 ≥ 0.70，但区间跨过 0.70 |
  | Fail | 点估计 < 0.70 |
  | Not estimable | 机构数不足 |

- **所需季度数**：用 Spearman–Brown 公式计算达到 0.70 所需的季度数，同时给出点估计及区间两端对应的值。区间下限 ≤ 0 时，上限记为“不可识别”。

## 7. Test 3：统计可比性

| 特征 | 定义 |
|---|---|
| 零分子比例 | 可分析记录中分子为 0 的比例 |
| 天花板效应 | 仅过程指标：取值为 100% 的比例 |
| 总事件数 | 可分析记录的分子之和 |
| 过度离散因子 | 仅感染结局：机构层面合并计数，Spiegelhalter 法，z 值按 10%/90% 缩尾 |

**判定**：

- Fail：天花板效应 > 25%；或总事件数 < 150 且零分子比例 > 75%；
- Conditional：零分子 > 75%、事件数 < 150、过度离散因子 > 10，三者出现任一项；
- Pass：以上都不出现。

## 8. 综合判定

按顺序判定：

1. Test 1 Fail、Test 3 Fail 或 Test 2 不可估计 → **Not usable as currently specified**
2. 三项全部 Pass → **Definitely usable for single-quarter comparison**
3. Test 1、Test 3 为 Pass，且 Test 2 为 Provisional → **Provisionally usable for single-quarter comparison**
4. 其余情况：所需季度数的区间上限 ≤ 12（三年）→ **Usable only with pooling and/or adjustment**；否则 → **Not usable**

第 4 类另列“需要做什么”，可能的内容有四种：

- 合并至少 k 个季度；
- 使用过度离散校正的控制限；
- 使用合并计数，而不是季度率；
- 只限有可分析数据的机构比较，并同时报告可得性。

这一列回应的问题是：过度离散不能靠合并季度解决。

这些规则是对 v1.6 代码（`p9b`）的修正，具体见第 13 节。用 v1.6 Table 4 的输入代入新规则，11 个指标的总评与 v1.6 完全相同，单元测试 `test_new_rules_reproduce_v16_verdicts` 已核对。

## 9. 补充分析

### 9.1 容量校正信度（Table S3）

- 对每家机构的合并估计，信度 r_i = τ² / (τ² + v_i)。
- 抽样方差 v_i：感染结局按泊松，v_i = λ / n_i；过程比例按二项，v_i = p(1−p) / n_i。
- 机构间方差 τ² 用 DerSimonian–Laird 加权矩估计。
- 至少 20 家机构才计算，否则显示“—”，不显示 0。

v1.6 用未加权矩估计，容易被分母极小、率极端的医院主导；这可能就是血透感染 ICC 只有 0.570、容量校正信度却高达 0.993 的原因。这一项只用于和 ICC 比较指标排序，不进入任何判定。

### 9.2 机构比较（Figure 4、Table S7–S9）

- 合并率与机构合并率的分位数，分全部、三级、二级三层；
- 漏斗图控制限按 √φ 放宽，并报告未校正与校正后在 95% 和 99.8% 控制限外的机构数；
- Gamma–Poisson 经验贝叶斯收缩同 v1.6。

### 9.3 示范分析（Table 5）

- **暴露**：每百床感控专职人员数，分解为医院间成分（机构均值）与医院内成分（季度偏离）。log 床位和器械使用率（CAUTI、CLABSI）同样分解。各项按记录标准化。
- **结局**：总 HAI、MDRO、CAUTI、CLABSI。
- **协变量**：三级、季度（分类变量），以分母对数作 offset。
- **模型**：见 D5。
- **稳定性**：不收敛或任一系数 |β| > 10，判为不稳定，不报告。
- **多重比较**：两个人员项按 BH 法校正，在每个结局 × 模型内计算。
- **解释**：只作测量论证的示范，不报告任何效应估计为发现，不作因果解释。

正文的论证改为：Poisson GEE 的稳健标准误已经能处理过度离散；两种模型结论不同，反映的是不同加权方式对少数大医院的敏感性，而不是“选错了分布”。

### 9.4 网络覆盖与上报流向（Table 1、Table S1、Figure S1）

- 框架机构数与已编码机构数来自质控中心，冻结后允许按其确认修改；上报机构数来自数据。
- 上报模式分为连续、永久停报、晚进入、晚进入后停报、间断五类，组别和 n 全部由数据计算。v1.6 的 `p5` 把组名和 n 写死在代码里。

### 9.5 机构特征（Table 2）

先取每家医院在主分析期内的中位数，再比较三级与二级医院（Mann–Whitney）。v1.6 在医院-季度层面检验，把同一医院的重复观测当作独立样本。

## 10. 敏感性分析

1. **阈值扫描**：所有务实阈值同乘 0.25–4 之间的 11 个系数，重算可分析比例、ICC 点估计和合并率（Figure S3）。v1.6 正文称扫描了 0.25–4 倍，但 ICC 实际只在 0.5、1、2 倍下计算过。
2. **判定界值**：ICC 界值取 0.60 或 0.80；Test 2 只看点估计；可得性 Pass 线取 70% 或 90%；合并期限取 8 或 16 个季度；零分子界值取 65%；过度离散界值取 5。沿用同一套自助区间，列出哪些指标的总评发生变化（Table S4）。
3. **分析集**：主分析集；平衡面板（主分析期每季度都上报）；包含不完整季度（Table S6）。
4. **指数定义**：9 模块、核心模块、v1.6 的 10 模块。

## 10A. 后果分析：不先做筛查就排名，会出现什么偏差

这一节回答一个问题：如果质控网络像现在这样，直接按上报的率给医院排名、表扬或督查，会得出多少站不住的结论。

**范围**

- 指标：全部 11 个指标中有至少 20 家医院可排名、且有事件的指标。
- 时期：
  - 主分析为最后一个主分析季度，模拟质控中心的季度排名；
  - 次要分析为全部主分析季度合并。
- 方向：感染结局和 I 类切口预防用药越低越好；手卫生和病原学送检越高越好（`config.BETTER`）。

**A 部分：只用上报数据**

- **A1 排名不确定性。** 先用经验贝叶斯建模：感染结局用 Gamma–Poisson，过程比例用 Beta–二项，先验参数都用矩估计。从后验中抽样 2 000 次，得到每家医院名次的 95% 区间，名次 1 为最好。报告以下几项：
  - 区间宽度的中位数，以占医院数的百分比表示；
  - 区间宽度 ≥ 50% 名次的医院比例；
  - 可信地位于前 25% 和后 25% 的医院数，判断标准是区间整体落在该范围内。
- **A2 粗率排名与校正方法的一致性。** 对按粗率排出的“最好 10%”和“最差 10%”，报告：
  - 最好 10% 中零事件医院的比例，只针对感染结局；
  - 最好 10% 中可信地位于前 25% 的比例；
  - 最差 10% 中可信地位于后 25% 的比例；
  - 最差 10% 中落在过度离散校正漏斗图 95% 上控制限之外的比例；
  - 最好 10% 与全部医院的可分析性指数中位数对比。
- **A3 朴素排名。** 模拟清洗前的数据，把分母为 0 或缺失的记录按率 = 0 处理，分母低于阈值的记录照常计算，按医院合并后排名。报告朴素排名“最好 10%”中完全没有可分析数据的医院数及比例。

**B 部分：质控中心的实际名单（有材料时才做）**

- **输入格式**：CSV 或 Excel，字段为 `ID, period, indicator, flag`。
  - `period`：季度（如 2025Q4）、年度（如 2025）或 `pooled`；
  - `indicator`：指标 key 或 `composite`；
  - `flag`：`good` 或 `bad`。
- **单项指标的结论**：同时满足以下三条，才算“得到数据支持”，否则写明不满足的原因：
  - 该医院在该期有可分析数据；
  - 该指标的三重检验总评不是 Not usable；
  - 该医院名次的 95% 区间整体落在相应的前 25% 或后 25%。
- **综合评分的结论**：无法拆分到单项指标，只报告该医院的可得性指数，以及有可分析数据的指标个数。
- **报告与保密**：报告得到支持的结论条数，以及各类原因的条数。机构一律用匿名编码，论文中不出现可识别信息。

**输出**：Table S11（汇总）、Table S12（逐院名次区间）、Table S13（质控名单比对）、Figure S4（总 HAI 最后一季的名次区间毛虫图）。
